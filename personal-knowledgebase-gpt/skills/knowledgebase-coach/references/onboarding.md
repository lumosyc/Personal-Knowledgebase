# 问答初始化与渐进画像

目标是少量对话就能开始，并在学习中继续完善；借鉴 prompt-clarifier 的语境复用、只问关键缺口、短问题和保守默认。此插件自带完整流程，不依赖另外安装 prompt-clarifier。

## 状态

`new → collecting → provisional / ready`。每轮把已答事实及 `next_question` 存盘；下次仅续问缺口。`ready` 表示已能提供个性化教学，不表示所有字段齐全或用户已掌握知识。

先读已存画像和当前任务。用户直接提供论文、题目或紧急学习任务时，问清本次目标即可开始；画像置 provisional，其他问题延后，不把入门问卷当成学习门槛。

## 推荐提问顺序（不是固定问卷）

1. **目标**：你最近最想用它解决什么？可选“读懂论文 / 跟上课程或考试 / 推进研究或项目 / 两者兼顾”。若用户已说清则跳过。把愿望转为能观察的产物，例如能独立做某类题、复现一个实验或解释一篇论文；不擅自填期限。
2. **背景与当前卡点**：你已经学过什么、目前最卡哪里？允许自然语言和“不确定”；不要求简历、年龄或真实姓名。熟悉度是自述，后面用一道小诊断题检验，不能直接作为 mastery。
3. **内容与约束**：有教材、课程大纲、论文或项目材料吗？时间预算或期限只有影响安排时才问；没有材料也可以先建立最小路径。
4. **互动偏好**：可给简短选择“具体例子 → 直觉 → 公式 / 直觉 → 公式 → 练习 / 先尝试做题再补概念”。中文对话可暂定中文为主、术语保留英文；标注 proposed，不反复追问语言。需要时了解反馈直接程度、希望避免的方式、可用类比领域；“不知道”采用短问题、温和直接反馈的可撤销默认。
5. **研究锚点**：仅 research / mixed 问目前最想回答的 1–3 个核心问题。不知道时依据用户目标提出候选，标 provisional，允许边读边确定；用户确认后才标 confirmed。纯课程模式允许没有 Q。
6. **收束并开学**：简短呈现画像关键事实、待定内容和本次第一步，邀请“直接开始 / 改一下”。这属于可纠正的教学回顾，不额外阻塞自动保存；用户已授权开始则立即进入第一次诊断。

通常 4–6 个短轮次足够；这不是次数要求。用户已给足信息时一轮生成并开始。按会改变路径的缺口追问；可继续学习就不要逼迫达到某个完整率。用户说“先开始”时不继续追问非关键字段。

## 最小可用画像

当前目标与模式明确；有背景线索或明确“未知、需要诊断”；有可撤销的教学默认；下一步学习对象明确。缺少称呼、长期研究问题、时间预算不会阻止学习。

## 提问规则

- 默认每条消息一个主问题，给 2–3 个易选方向并始终接受自由文本、跳过、不确定。若宿主有文字问题工具可以使用，没有就直接在聊天中提问。
- 不复问已给背景，不一口气抛几十项字段，不显示内部置信度分数。
- “个性化 / 个性”落实为互动与表达偏好：节奏、公式深度、反馈语气、熟悉领域、认知负担。不要把偏好归为固定人格标签。
- 保存用户原话或可验证表现，并分别标 `user-stated`、`observed`、`proposed`。观察与自述冲突时先保留两者、用小题澄清，不静默覆盖身份事实。
- 用户随时可说“修改画像”“换目标”“我只有 15 分钟”“别用这个类比”。只改受影响字段和相关路径；Q 编号不重排，旧问题可标 retired。

## 中断恢复

保存 collecting + 下一待问问题。新聊天读取 `onboarding.next_question`；用一句话复述已知目标再续问。provisional 用户直接学习时不强制回到问卷，遇到影响教学的缺口再问。
